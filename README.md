# Monitor Tool

一个面向 Windows 的轻量硬件状态监控桌面端原型。它提供可配置的桌面浮窗、实时仪表盘和按需展示的硬件指标。

## 当前能力

- CPU 利用率、频率与可用时的温度
- 内存利用率与已用容量
- GPU 利用率、温度、显存与设备信息（取决于显卡驱动可提供的数据）
- 自带 Libre Hardware Monitor 本地桥接：温度、功耗、风扇与主板传感器
- 可选“管理员增强采集”：仅提权本应用自带的桥接器，以尝试读取 CPU MSR、Super I/O 与主板风扇；不依赖或启动 HWiNFO
- 磁盘利用率、上下行网络速率
- 桌面浮窗：置顶、锁定/鼠标穿透、透明度、比例、紧凑/展开/横向布局与位置记忆
- 通过“显示项”勾选并拖动排序浮窗内容；设置会持久化到当前 Windows 用户的应用数据目录
- 实时页保留最近 120 个采样点的短时趋势图
- 独立历史趋势页：可开关本地日志、设置 1 小时至 30 天最长保留周期，超期记录自动清除，并按时间回看历史曲线
- 可选 CPU/GPU 温度阈值告警；默认关闭，同一告警使用冷却时间避免重复通知
- 轻量模式：关闭主界面后释放主界面渲染进程，仅保留浮窗、托盘与传感器；需要设置或历史曲线时从托盘重新打开

轻量模式下，采集服务会按浮窗当前勾选项建立采集计划；未显示的内存容量、磁盘、网络、频率等指标不会重复调用对应系统接口。若开启温度告警，CPU/GPU 温度会继续后台采样。

## 启动

```powershell
npm install
npm start
```

## Windows 正式程序

开发模式下运行的进程名仍会显示为 Electron；正式打包后会使用 `Monitor Tool` 产品名、`MonitorTool.exe` 可执行文件名和项目 Logo。

```powershell
# 生成可运行的未安装目录，用于检查进程名称与图标
npm run pack

# 生成 Windows 安装包
npm run dist
```

## 传感器边界

基础的 CPU、内存、磁盘和网络数据不需要管理员权限。温度、风扇、部分功耗与主板传感器受设备、驱动和 Windows 安全策略影响，可能不可用；界面会显示“暂不可用”，不会以猜测值替代。

“增强硬件传感器”默认开启。应用会启动随程序打包的 Libre Hardware Monitor 0.9.7-pre731 本地桥接进程并按需读取数据，不会把传感器数据发往网络。该官方预发布库已含 MSI X870(E) / Nuvoton NCT6687D-R 的适配代码；桥接器会保留主板与 Super I/O 子设备层级，因此风扇与主板温度不会因设备树扁平化而丢失。

默认“标准”模式不请求管理员权限。若设置页显示 CPU 温度/功耗已识别但数值无效，或主板/CPU 风扇未上报，可由用户切换到“管理员增强”；此时 Windows 会显示 UAC，由用户自行确认。该模式不会修改 BIOS、风扇曲线或 Windows 安全设置；如果仍无读数，应用会如实显示不可用而不会伪造数据。

新版 LHM 对主板 Super I/O 需要 PawnIO 底层驱动。项目已内置官方签名的 PawnIO 2.1.0 安装器：管理员增强模式检测到缺失时，设置页会显示“安装传感器驱动（内置 · 仅一次）”。用户点击后由应用校验 SHA-256、请求 Windows UAC，并等待官方安装器完成；安装成功后应用自动重连传感器。它不是常驻的 HWiNFO 类监控程序，也不会下载未知文件、修改 BIOS 或写入风扇控制值。

## 第三方组件

`resources/lhm/` 包含 Libre Hardware Monitor 0.9.7-pre731 的运行文件，以及本项目的标准/管理员增强 JSON 桥接程序。Libre Hardware Monitor 使用 MPL-2.0；发布产品时请一并保留该目录中的第三方说明，详情见 `resources/lhm/THIRD_PARTY_NOTICES.md`。
