# Windows 更新通道

客户端通过主进程访问 `https://download.carl.top/api/v1/apps/monitor/` 下的接口：

- `check`：参数 `version` 使用应用真实版本，不固定为示例版本；另附 `platform=windows` 和通道 token。
- `latest`：发现新版时补充版本说明、文件大小和可选的 SHA-256。
- `download`：点击下载安装或手动下载后才使用，服务端应返回 Windows Setup 安装包，不是便携版。

## 通道配置

将 `update-channel.example.json` 复制为项目根目录的 `update-channel.local.json` 并填写 token。本地配置已加入 Git 忽略；打包时仅将它复制到应用的 resources 目录，不提交到公共源码仓库。运行时也可通过 `MONITOR_TOOL_UPDATE_TOKEN` 环境变量覆盖。没有本地配置的源码构建仍可使用监控功能，但更新检查会提示通道未配置。客户端分发包内的配置可被用户读取，因此服务端 token 应仅具备该应用的版本查询和下载权限。

## 当前接口核实结果

2026-10-24 联调时，`check` 使用客户端版本 `1.0.0` 能返回 `version: "1.0.1"`、`update: true`；`latest` 同样返回有效的 `1.0.1` 版本信息。下载接口通过重定向提供 Setup 文件。未发布时的 `{"latest":null,"update":false}` 与 `latest` HTTP 404 仍显示为“暂未发布 Windows 版本”。

Electron 的 `fetch` 使用 `redirect: 'manual'` 会直接抛出 `Redirect was cancelled`，因此不能用它读取 302 后再手动逐跳请求。客户端使用独立、无磁盘缓存的更新会话自动跟随跳转，通过该会话的 `webRequest` 限制每一跳必须是 HTTPS、不得携带 URL 用户名密码，且最多跳转 5 次。

修复后的 Electron 下载探针已完整下载当前通道的 116,803,798 字节文件，通过大小与 Windows PE 格式校验。独立计算的 SHA-256 与原始本地 1.0.1 安装包一致；探针替换了安装动作，没有执行安装器。修复版两个安装包输出至 `dist/update-fix/`，验收更新时应先安装其中的 1.0.0，再将通道中的 1.0.1 安装包替换为同目录的新包，避免更新后重新装入旧客户端。

已发布版本需包含有效的语义化 `version`，例如 `1.0.0`。客户端支持 `latest` / `data.latest` / `release` / 直接版本对象；可选字段包括 `release_notes` / `changelog` / `notes`、`file_size` / `size`、`sha256`。版本说明按纯文本展示。服务端提供 SHA-256 时会强制验证；格式无效、校验失败、大小不匹配、非 Windows PE 文件均停止安装。未提供 SHA-256 时不声称已进行哈希验证。

## 使用与边界

- 默认安装版启动 8 秒后检查一次，可在关于页关闭；没有常驻定时轮询。
- 没有更新或网络失败时，启动检查不弹干扰窗口；关于页保留检查结果。
- 发现新版显示与应用主题一致的独立窗口，后台启动时不加载整个主面板。
- 用户点击“下载并安装”后才下载，显示进度，可取消；完成格式及可用校验后启动安装器并退出当前应用。不会静默下载或强制安装。
- 下载失败可重试；部分文件会清理。关闭下载窗口会取消当前下载，退出应用会终止检查和未完成下载。
- 启动时仅在专用更新缓存目录中清理过期的自有下载文件：未完成文件超过 1 天、安装包超过 7 天；不递归删除目录，也不处理其他文件。
- 开发环境不执行安装；便携模式不自动覆盖，提供手动下载。当前通道约定提供 Setup，便携包仍从 GitHub 获取。
- 安装器运行前应用会退出，安装后的启动行为由现有 NSIS 安装包决定。Windows 仍可能拦截未签名的安装包；客户端不会绕过系统安全策略。
- 只发送版本号、平台及通道鉴权信息，不上传硬件采样或历史日志。
- 检查或下载异常会记录至应用用户数据目录的 `update-diagnostics.jsonl`，包含阶段、错误码和经过脱敏的简短堆栈；不记录 token 或 URL 查询参数。界面按网络、代理、证书、磁盘与客户端异常分别提示。

发布前需验收：已是最新 / 有更新 / 未发布 / 网络失败、深浅主题、下载取消与重试、校验失败、Windows 安装器启动和更新后版本显示。下载探针会替换安装动作，只验证实际文件传输与格式校验，不自动安装或关闭用户正在运行的应用。
